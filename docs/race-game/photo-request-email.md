# Photo request email (race organisers and photographers)

Fill the [brackets]. One email per race. Send to the race's media or press contact
if it has one, otherwise the general address.

---

**Subject:** Can we use a [Race] photo in a running quiz?

Hi [Name],

I'm Stephen Cousins and I run Film My Run (filmmyrun.com). I've been filming
races for years, mostly from the middle of the pack with a camera in my hand.

I'm building a free daily quiz for runners. It shows a photo, an elevation profile
or a course map, and you have to guess the race. Think GeoGuessr, but for ultras.

[Race] is one of THE races, so it has to be in there. But I can't use photos I
don't have permission for. So I'd love to ask: could we use two or three of your
photos?

What you'd get:

- A credit on every photo, with the photographer's name and a link to your site
  or theirs.
- A link to [Race] on the answer screen, where players read about the race.
- Nothing changed. We'd crop to fit the screen and that's it.

Scenery and runners on the course work best. Ideally nothing with the race name
in shot, or it gives the answer away!

If you're happy, just reply with the photos (or a link) and tell me how you'd like
the credit worded. And if you'd rather not, no problem at all.

Thanks,

Stephen Cousins
Film My Run
filmmyrun.com
