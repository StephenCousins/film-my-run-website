How it scores

Four scales, one closest type

  • Each answer nudges one to three scales: Road or Trail, Data or Feel, Short or Long, Racer or Social.
  • Scores are scaled against how answers usually fall, so no scale leans one way by default.
  • You get the closest type, plus the next closest as "a streak of".
  • Tested with 20,000 random answer sets: every type comes up, none more than 18% of the time.
